# Breath of the Wild Manual APWorld

This is an Archipelago Manual for The Legend of Zelda: Breath of the Wild that involves using a custom save file and [Marc Robledo's save editor](https://www.marcrobledo.com/savegame-editors/zelda-botw/) to adjust the inventory and flags in a playthrough as you send and receive items. It works with both the Wii U and Switch versions of the game.

Due to the information being somewhat extensive, all setup and playthrough instructions can be found [here.](https://docs.google.com/document/d/1ensvYR2znB5WThGhfeK__oLj4iIF-xleWlTsNNhPSDU/edit?usp=sharing)

It is also recommended to use [this program](https://github.com/JDLKMR/BotW-TotK-AP-Manual-Sync) alongside the Manual to automate the save editing process.
